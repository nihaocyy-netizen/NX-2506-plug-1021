# mytool-1021

适用于 Siemens NX 的建模与工程辅助工具集。工具通过 NX 菜单加载 Python、VB 和 DLX 界面，集中处理模型显示、图层整理、自动出图、常用特征创建以及 CAD 文件批处理。

## 1. 项目解决的问题

在日常 NX 建模和工程协作中，以下操作通常需要重复点击多个原生命令，或依赖人工逐个处理：

- 给多个实体统一改色、设置透明或只显示目标对象；
- 在图层之间切换、批量显示/隐藏图层、整理实体所在图层；
- 为多个实体重复创建三视图并手动排列、标注；
- 创建快捷腰孔、插入螺钉、查询尺寸公差等常用操作；
- 将多个外部 CAD 文件逐个导入，或将多个 NX 部件逐个转换为 STEP/IGES；
- 在不同 NX 版本或不同 Windows 语言环境下手动配置菜单路径。

本项目把这些操作整合到 NX 菜单中，并提供图形化安装器。安装器会自动识别 NX 安装目录、按 Windows 语言选择简体或繁体菜单，并将插件目录写入 NX 的 `custom_dirs.dat`，减少手工配置。

## 2. 主要功能

安装成功后，NX 菜单栏会出现“NX工具”和“NX插件”级联菜单。具体名称会随 NX 语言环境显示为对应语言。

### 2.1 颜色工具

路径：`NX工具 > 颜色工具`

- 红、橙、黄、绿、蓝、棕、灰、紫、黑；
- 随机颜色；
- 支持对当前选择的实体或可显示对象执行操作。

### 2.2 显示工具

路径：`NX工具 > 显示工具`

- 设置透明：默认透明度为 50；
- 取消透明；
- 仅显示：隐藏其他对象，只保留选定对象可见。

### 2.3 图层工具

路径：`NX工具 > 图层工具`

- 显示全部图层、隐藏全部图层；
- 上一图层、下一图层；
- 图层分离：将选定实体依次放入不同图层，默认从 150 层开始；
- 10 为工作层、200 为工作层；
- 移动到 255 图层。

支持撤销的操作可以使用 NX 的撤销命令或 `Ctrl+Z` 回退。

### 2.4 自动出图

路径：`NX工具 > 自动出图`

- 自动出图：选择一个或多个实体，生成主视、侧视、俯视三视图，自动排列到图纸并标注长、宽、厚；
- 半自动出图：通过界面选择实体，按任务进度逐个处理，适合需要人工确认的流程；
- 重置出图：清除半自动出图的临时进度，重新开始任务。

自动出图前建议隐藏无关实体，并确保当前处于建模环境、零件已经保存。

### 2.5 应用工具

路径：`NX工具 > 应用工具`

- 截图工具；
- 尺寸公差查询：启动 `exefile/GongCha.exe`；
- 计算器；
- 快捷腰孔：输入腰孔尺寸、方向和位置，预览后应用参数化特征；
- 螺钉插入：通过 NX 对话框设置螺钉类型、长度和方向，生成可编辑的螺钉特征。

### 2.6 导入导出

路径：`NX工具 > 导入导出`

批量导入支持：`.prt`、`.stp`、`.step`、`.igs`、`.iges`、`.x_t`、`.x_b`。每个文件会作为独立部件加入当前 NX 会话。`.prt` 只打开、不另存；STEP、IGES、Parasolid 会在源文件同目录生成同名 `.prt`，同名时自动使用 `_2`、`_3` 等后缀。

批量导出支持将一个或多个 `.prt` 导出为 STEP 或 IGES，可递归处理目录，可指定输出目录、文件名前缀和后缀，并在导出后校验结果。STEP 导出默认只导出当前工作视图中可见的图层。STEP 导出需要 NX 的 STEP Translator 许可；IGES 导出需要 NX 自带的 IGES 转换器可用。

## 3. 安装方法

### 3.1 使用安装器安装

1. 将整个 `mytool-1021` 文件夹解压到固定路径，建议使用不含中文和空格的路径，例如 `D:\mytool-1021`。
2. 关闭正在运行的 NX。
3. 双击项目根目录下的 `PD-NX插件安装.exe`。
4. 安装器通常会自动识别 NX 安装目录。若未识别到，点击“浏览”选择包含 `UGII` 文件夹的 NX 根目录，例如 `C:\Program Files\Siemens\NX 12.0`。
5. 点击“安装插件”。安装器会将插件目录写入 `<NX安装目录>\UGII\menus\custom_dirs.dat`。
6. 重新启动 NX，打开任意 `.prt` 文件。菜单栏出现“NX工具”和“NX插件”后，安装完成。

安装器支持安装状态检测和卸载；如果 `custom_dirs.dat` 是只读文件，安装器会临时处理只读属性，写入后恢复原状态。

### 3.2 安装后检查

确认 `application`、`bitmap`、`startup` 三个目录仍然位于同一个项目根目录下，不能单独移动。脚本和菜单通过相对路径查找界面文件、图标和其他资源。

## 4. 使用方法

### 4.1 一般操作流程

1. 启动 NX 并打开或新建零件。
2. 在图形窗口中选择实体、特征或其他可显示对象。
3. 从 NX 菜单选择对应功能。
4. 按弹出的 NX 对话框或文件选择窗口填写参数。
5. 执行后检查模型、图纸或输出目录中的结果。

涉及对象的命令通常要求先选择对象；如果没有选择对象，命令会提示未选择或直接结束。

### 4.2 半自动出图流程

1. 打开需要出图的零件并选择实体。
2. 点击 `NX工具 > 自动出图 > 半自动出图`，按界面提示确认。
3. 完成当前实体后再次运行半自动出图，切换到下一个实体。
4. 全部完成后点击“重置出图”清除任务进度。

临时进度文件位于 Windows 临时目录。任务异常中断时，优先使用“重置出图”重新开始。

### 4.3 批量导入流程

1. 点击 `NX工具 > 导入导出 > 文件批量导入`。
2. 选择一个或多个支持的文件，点击“确认导入”。
3. 检查会话中的独立部件和源文件目录中的新 `.prt` 文件。
4. 排查失败时查看 `application\logs\batch_import.log` 和 `batch_import_trace.log`。

### 4.4 批量导出流程

1. 确认 NX Translator 许可可用。
2. 点击 `NX工具 > 导入导出 > 文件批量导出`。
3. 选择目录或文件，在预览窗口确认清单、格式和输出位置。
4. 点击“确认导出”，检查 `.step` 或 `.igs` 文件及 `application\logs\batch_export_step.log`。

导出前请先在 NX 中设置需要导出的图层可见性。

## 5. 案例演示

### 案例一：整理装配模型的显示效果

框选实体后使用 `NX工具 > 颜色工具 > 随机颜色`；选择目标零件后使用 `显示工具 > 仅显示`；检查完成后使用 `显示工具 > 取消透明`，需要恢复全局显示时使用 `图层工具 > 显示全部图层`。这样可以快速区分并定位目标实体。

### 案例二：将多个 STEP 文件转换为 NX 部件

打开 `文件批量导入`，按住 `Ctrl` 或 `Shift` 多选 STEP 文件并确认。工具会为每个文件创建独立部件，并在源目录生成对应的 `.prt`；已有同名文件会自动使用 `_2`、`_3` 后缀。

### 案例三：批量输出可见几何的 STEP 文件

先确认需要输出的图层可见，打开 `文件批量导出`，选择项目目录和 `.prt` 清单，选择 STEP 格式并确认导出。检查生成的 `.step` 文件和日志；隐藏图层中的实体不会进入默认 STEP 输出。

```text
├─ bitmap/                   菜单按钮图标

```

## 7. 常见问题

- **菜单没有出现**：确认 NX 已完全关闭后重新启动；检查 `custom_dirs.dat` 中是否包含项目根目录。
- **按钮提示找不到 DLX 或图标**：检查项目是否完整解压，尤其是 `application\*.dlx` 和 `bitmap` 目录。
- **批量导出失败**：确认 STEP Translator 许可、输出目录写权限，以及源部件能否在 NX 中正常打开。
- **自动出图视图缺线**：出图前隐藏无关实体，避免其他实体遮挡当前实体。
- **螺钉或快捷腰孔创建失败**：检查目标实体、入口面、方向和参数是否有效；重新启动 NX 后再试可排除旧模块缓存影响。
